# ltbot 产品档案与原型视觉规范

> 参考 nextapp 产品 Skill 的文档可读性规范，但配色取自 ltbot 当前工作台/知识库的蓝灰界面；只约束本 Skill 生成的 HTML 文档和原型，不冒充应用全局设计系统。

## 色彩与字级

| 用途 | 建议值 | 依据 |
| --- | --- | --- |
| 背景 | `#f5f7fb` | 工作台/知识库页面背景 |
| 面板 | `#ffffff` | 卡片与文档表面 |
| 主文字 | `#172033` | 工作台正文 |
| 次文字 | `#667085` | 工作台说明 |
| 边线 | `#e6eaf2` | 工作台分隔 |
| 交互蓝 | `#3f7cff` | 工作台主色 |
| 柔和蓝 | `#ebf2ff` | 工作台辅助背景 |
| 成功/警告/错误 | `#16a36f` / `#d97706` / `#dc2626` | 文档状态语义，不宣称应用统一 token |

正文用系统中文字体，16px 左右；一级标题 30–42px，二级标题 22–30px；元信息 13–14px。代码用 Consolas/等宽字体。文档建议最大宽 1100px；大屏左侧 230–250px 导航，窄屏改单栏。卡片圆角 10–14px，焦点可见，正文对比度优先。

## 文档组件与内容规则

- 时间线：首页最新在前；每条记录显示日期、主题、状态与当前版本。
- PRD：背景/证据、目标/非目标、场景、流程和状态、依赖、验收、风险、版本变更。
- 原型：清楚标注“现状示意”或“提案”，标注静态内容、接口数据、外站链接与待验证处；原型不等于上线证明。
- 表格可横向滚动；移动端导航折叠；打印时保留主内容。
- 任何密钥、token、密码或私密连接串在生成 HTML 前脱敏为 `***`；不得放入原型素材。
