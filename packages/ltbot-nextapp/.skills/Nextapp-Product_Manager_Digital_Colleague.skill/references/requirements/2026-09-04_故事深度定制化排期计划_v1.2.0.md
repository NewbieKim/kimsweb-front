# 故事深度定制化改造排期计划 v1.2.0

> 对应：[故事深度定制化 PRD v1.2.0](2026-09-04_故事深度定制化PRD_v1.2.0.html)  
> 状态：技术评审修订版，待确认后进入开发。

## 第一期：私密定制闭环与访问安全

目标：先让产品可靠地记住孩子并生成私密专属故事。公开、审核、真人照片、积分奖励均不进入本期。

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 隐私与访问底座 | 统一 PUBLIC/PRIVATE 访问策略、所有权校验、历史故事 PUBLIC 回填、移除敏感日志 | 非作者无法读取新 PRIVATE；历史故事维持当前公开行为 |
| 数据模型 | ChildProfile、StoryCustomization 一对一快照、Story.childProfileId/visibility、序号原子计数 | 不覆盖 extData；并发下序号不重复 |
| 档案与创作 | 多档案、预设头像、今晚小事、口味/语气、档案带入和切换确认 | 二次创作不重填；高风险素材不进模型 |
| 回执与个人资产 | 生成中提示、专属回执、详情摘要、按孩子筛选、同档案续讲 | 回显至少 5 个非空元素 |
| 验收灰度 | 接口/移动端/生成/TTS/积分回归，白名单观察 | 无私密越权、日志无敏感数据、生成成功率不降 |

## 第二期：真人照片、公开发布与审核

进入条件：对象存储与照片生命周期方案、真实 MIME/尺寸校验、EXIF 清理、内容审核服务/回调验签、人工下架流程已确认；第一期访问策略通过回归。

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 真人照片 | 监护人上传、私有对象存储、签名访问、删除清理 | 公共响应绝不返回照片对象 key |
| 公开发布 | PUBLIC_PENDING、监护授权、审核中/通过/失败、公开转私密 | 审核中不进广场；转私密立即下架 |
| 公开奖励 | 审核通过后 5 积分；storyId 唯一、用户自然日一次、迟到回调防护 | 服务端事务/唯一约束证明无重复发奖 |

## 第三期：内容丰富与长期陪伴

只在前两期数据达标后选择一个方向优先推进：场景库、主题推荐、TTS 扩容、伙伴宠物、故事墙、轻打卡、成长里程碑或绘本导出。不得全部并行。

## 固定评审清单

- 新私密故事是否在列表、详情、互动、解锁、异步生成各入口都被访问策略保护。
- 历史故事是否全部按事实保持 PUBLIC，且没有意外下架。
- 快照是否独立于 extData，生成接口是否只读数据库快照。
- 日志、埋点、错误上报是否不含昵称、今晚小事、照片或环境变量。
- 真人照片、公开、审核、奖励未达到第二期前置条件时，是否无法被误开启。
