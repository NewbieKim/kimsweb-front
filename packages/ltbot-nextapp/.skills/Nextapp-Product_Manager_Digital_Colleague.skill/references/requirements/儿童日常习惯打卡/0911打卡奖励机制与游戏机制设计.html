奖励 / 养成小游戏 · v0.2.0

打卡奖励机制与游戏机制设计

让孩子完成日常习惯后，立刻获得一张食物卡，亲手喂养孩童档案中的小伙伴；小伙伴用看得见的动作、房间和成长阶段，持续回应孩子的每一次回来。

2026-09-11 ｜ 状态：方案 v0.2.0，已并入 PRD v0.4.0 ｜ 体验高保真原型 v0.4.0 ｜ 本文是来源材料，不是当前开发契约

1. 核心结论

★
推荐产品形态：一只会回应、会成长、不会因缺席受伤的小伙伴。
主循环是“完成习惯 → 三选一食物卡 → 喂养 → 即时反应 → 营养环点亮 → 阶段成长”。账户积分继续只服务故事生成；食物卡、成长值和装扮全部归属 ChildProfile。
定位

习惯养成 × 陪伴养成

核心不是营养计算器，也不是电子宠物商城，而是把真实打卡转化为“我照顾了小伙伴”的即时成就。

教育

认识食物，不背剂量

卡面展示食物来源、主要营养作用和一句儿童语言知识；不显示克数、毫克和补充剂建议。

增长

每天都有反馈，数周可见成长

单次完成有动画与卡片；3–7 天有外观变化；30–60 天形成长期收藏与情感资产。

!
不要设计“蛋白质达到 X 就长高 Y 厘米”。真实身高由遗传、总体膳食、睡眠、运动与健康等多因素共同影响。产品可使用“长高一格 / 成长阶段”这种明确的游戏刻度，但必须标注它与真实儿童或真实动物身高没有换算关系。

2. 研究与产品依据

证据 / 产品观察本产品采用不照搬
Codex Pets伙伴常驻、以少量动画状态映射真实任务进度，点击可回到任务。伙伴常驻打卡页；用“等待、开心、成长、入睡”表达进度。不复制浮窗形态，不让动画脱离儿童习惯链路。
Codex Pet Arena先做收集、变大、反馈的可玩循环，再替换正式角色与增加特效。先用 1 只伙伴 + 12 张卡验证循环，再扩美术与房间。不做战斗、竞争、排行榜和掉落损失。
Finch完成目标会帮助伙伴成长，目标与陪伴形成持续关系。每次习惯完成都让伙伴有可见回应。不把成人自我照护复杂工具直接移植给儿童。
营养游戏研究游戏化更稳定地提升的是营养知识；对真实体重/饮食改变的证据更有限。首期承诺“认识与愿意尝试”，真实饮食改变只做探索性指标。不宣传能改善身高、BMI、挑食或治疗营养问题。
自我决定理论自主、胜任与连接感有助于游戏乐趣和持续参与。三选一卡（自主）、成长反馈（胜任）、伙伴回应（连接）。不靠连续签到焦虑和稀有抽卡维持参与。

产品推断：Codex Pets 的价值在“状态即反馈”，Pet Arena 的价值在“先调核心循环”。二者都不是儿童营养产品，本文只借其交互原则。

3. 核心游戏循环

1 · 真实行动完成今日习惯刷牙、洗澡、收玩具、阅读、听故事、按时睡前准备
→
2 · 自主选择三选一食物卡系统优先补齐当天缺少的营养属性
→
3 · 亲手互动拖到碗里喂养伙伴跑来、咀嚼、眨眼、说一句话
→
4 · 可见进步点亮营养环卡册收集、花园变化、成长一格

3.1 为什么是“三选一”，不是盲盒

  • 孩子拥有选择权，减少纯随机拿到重复卡的挫败；选择本身只有 2–3 秒，不拖长链路。
  • 后台使用“缺口优先”权重：三个候选至少一个补齐当前阶段最弱属性，但不向儿童展示算法。
  • 所有首发卡同等级、无付费抽取、无稀有概率；收藏乐趣来自图鉴、伙伴反应和组合，而非博彩式刺激。

4. 营养系统 v0.1

i
术语统一：儿童获得的是“食物卡”；食物卡携带 1–3 个“营养属性”。属性点只用于游戏平衡，不代表食物真实含量、儿童摄入量或每日推荐量。
⚡

活力能量

儿童语：跑跑跳跳和思考都需要能量。主要卡：米饭、燕麦、红薯。

💪

成长蛋白

儿童语：帮助身体建造和修补。主要卡：鸡蛋、鱼、豆腐、瘦肉、奶类。

🦴

骨骼钙

儿童语：和维生素 D 等一起帮助骨骼和牙齿。主要卡：奶类、豆腐、部分绿叶菜。

🚂

元气铁

儿童语：帮助血液把氧气送到身体各处。主要卡：瘦肉、豆类、蛋和强化谷物。

🌈

缤纷维生素

儿童语：不同颜色的食物带来不同小帮手。主要卡：蔬菜、水果、蛋、鱼。

💧

清爽水分

儿童语：让身体好好工作。主要卡：白水、奶类、水果和蔬菜。

4.1 为什么首版只有 6 轨

0–8 岁真实营养还涉及脂肪、碳水化合物、锌、碘、维生素 D、膳食纤维等。首版把宏量营养的游戏表达收进“能量 / 蛋白”，把多种维生素收进“缤纷维生素”，保留儿童阶段特别值得认识的钙、铁和水分；膳食纤维、维生素 D 等放在卡背知识标签中。这样既不会把 UI 做成营养成分表，也给后续扩展留下空间。

6. 成长规则 v0.1

6.1 奖励发放

  1. 每个有效习惯在设定时段内首次完成，生成 3 张候选卡；孩子选 1 张入背包。撤销打卡会回收尚未喂养的对应卡。
  2. 每天最多 3 次食物卡奖励；额外习惯仍有庆祝动画和历史记录，但不继续掉落，避免用任务数量堆成长速度。
  3. 喂养一张卡获得 2 成长值；当天首次集齐 4 种不同营养属性，再获得 2 点“彩虹餐盘”奖励。每日成长值上限 8。
  4. 重复卡可以继续喂养；图鉴只记第一次发现。背包上限建议 30 张，满后自动转入“食物相册”，不出现浪费或丢弃文案。

6.2 阶段门槛

🐣

初见伙伴 · 0–19

会眨眼、跟随手指；解锁名字牌。

🐰

活力幼崽 · 20–59

体型长高一格；解锁摸头与开心转圈。

🐇
阶段 3

好奇伙伴 · 60–139

解锁房间角落探索和第一件装扮。

🐇
阶段 4

探险伙伴 · 140–299

解锁花园探索动作与新的互动表情。

🐇
阶段 5

星光伙伴 · 300+

解锁专属房间主题与阶段纪念册。

节奏估算：若每日获得 4–8 成长值，约第 3–5 天首次长高、7–15 天进入阶段 3、18–35 天进入阶段 4、38–75 天进入阶段 5。实际阈值需用首批家庭 D7/D30 数据调参。

6.3 营养门槛不是“越多越好”

阶段升级同时要求点亮至少 4 类营养属性；界面使用环形拼图，不给孩子展示“缺铁”“营养不良”等诊断性文案。当某一类长期偏少，下一次三选一卡至少出现一张补齐卡。数值溢出不产生暴击、稀有度或更快“真实长高”。

7.1 首期互动动作

轻触摸头

伙伴闭眼、发出短音效，每次会随机说一句积极回应；不发奖励，避免无意义连点。

拖卡喂养

食物沿抛物线进入碗，伙伴跑来并根据食物做不同动作；核心反馈控制在 1.5–2.5 秒。

状态待机

未打卡时整理花园，完成时跳跃，全部完成时撒花庆祝；不出现饥饿、哭泣或生病。

夜间入睡

到家庭设定的睡前时段后，花园变暗、伙伴打哈欠；轻触伙伴会挥手并进入安静待机。

7.2 伙伴目录建议

用户提供的伙伴选择图是很好的首期结构：小猫小狗小兔子原创青蛙原创宇航员自定义。但当前源码实际是“小猫 / 小狗 / 小兔子 / 芭比娃娃 / 奥特曼”。两者需要在开发前统一；持久养成和对外宣传建议使用原创角色，避免第三方角色授权风险。

↔
切换伙伴规则：成长进度属于孩子，不属于某个皮肤。更换外观不清零成长值、卡册和房间；伙伴名字可单独设置。这样不会因为家长改档案而摧毁长期资产。

8. 0–8 岁分层

档案年龄谁操作信息密度重点体验营养内容边界
0–2 岁家长代理，孩子观看大图标、语音、单步喂养伙伴回应与亲子共看，不要求孩子理解规则不提供实际喂养建议；特别提示 0–6 月龄不应把食物卡当作添加辅食指引
2–4 岁孩子点选，家长配置图像为主，一句短文案拖拽、模仿声音、认识食物颜色强调“多样食物”，不做摄入量和好坏评分
4–6 岁孩子主操作图像 + 营养图标 + 简短解释三选一、集齐营养环、房间变化认识食物类别和作用，不诊断挑食
6–8 岁孩子自主，家长可回顾可翻卡背、看图鉴与阶段目标收集、组合、主动选择、花园养成可增加“为什么”知识，但不推荐补充剂或治疗方案
!
现有 ChildProfile 只有“0–2”年龄段，无法区分 0–6 月龄与 7–24 月龄。如果未来要给出年龄相关的真实饮食建议，必须先增加出生日期/月龄并经过专业审核；MVP 因此只做食物认知游戏，不做个体化喂养建议。

9. 数据与规则模型

9.1 现状与新增

已具备：ChildProfile、partnerJson、孩子档案 CRUD、故事绑定与快照。尚缺：伙伴成长状态、食物卡库存、奖励幂等、喂养记录和成长里程碑。

模型关键字段作用 / 约束

9.2 推荐接口

  • GET /api/child-profiles/:id/companion：伙伴、阶段、营养环、背包摘要、今日状态。
  • POST /api/habit-check-ins/:id/reward-candidates：幂等创建三张候选卡。
  • POST /api/habit-check-ins/:id/reward-selection：选择并入背包。
  • POST /api/child-profiles/:id/companion/feed：事务扣卡、加属性、加成长值、触发里程碑。
  • GET /api/child-profiles/:id/food-album：图鉴和发现时间。

12. 风险与边界

营养误导

所有数值标为游戏属性；不显示推荐摄入量、补充剂、身高厘米换算；卡背专业终审。

0–2 岁误用

默认家长代理；突出“食物认知游戏，不是喂养建议”；未具备月龄前不做个体建议。

过度任务化

每天最多 3 张卡和 8 成长值；不按习惯数量排名；允许休息，不清零成长。

情绪绑架

伙伴永不生病、挨饿、离家或责怪孩子；缺席后只说“欢迎回来”，不显示断签损失。

版权角色

持久养成首发使用原创动物/幻想伙伴；第三方知名角色在取得授权前不进入正式素材。

作弊与重放

以 checkInId 做奖励幂等；时段、孩子、习惯三层校验；撤销采用状态冲正，保留审计记录。

13. 已确认结论

  1. 伙伴首发目录：采用小猫 / 小狗 / 小兔子 / 原创青蛙 / 原创宇航员 / 自定义；正式养成目录不使用未授权的“芭比娃娃 / 奥特曼”。
  2. 领卡方式：采用三选一，系统保证至少一张补齐营养属性缺口。
  3. 成长归属：成长属于 ChildProfile；更换伙伴外观保留成长值、卡册和花园。
  4. 故事联动：首期不做故事跳转，也不把今日食物或伙伴阶段写入故事生成。
