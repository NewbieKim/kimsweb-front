# 故事深度定制化改造排期计划 v1.3.0

> 对应：[故事深度定制化 PRD v1.3.0](2026-09-04_故事深度定制化PRD_v1.3.0.html)  
> 状态：第二期产品方案已确认，待技术评估后填写负责人和日历日期。  
> 口径：只维护一个当前计划；估算以工作包和依赖表达，不在团队产能未知时承诺日期。

## 第一期：私密定制闭环与访问安全（第二期硬前置）

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 访问安全 | PUBLIC/PRIVATE、作者所有权、公共/作者 DTO 分流、历史故事 PUBLIC 回填、敏感日志治理 | 非作者无法通过列表、详情、互动、解锁和生成接口读取新 PRIVATE |
| 定制数据 | ChildProfile、StoryCustomization 独立快照、原子序号 | 不覆盖 extData；并发序号不重复 |
| 私密创作 | 多档案、预设头像、今晚小事、专属回执、同档案再讲一个 | 第二次创作不重填；高风险素材不进模型 |

第二期上线前必须完成第一期端到端权限回归。不能只做“锁”图标或前端筛选。

## 第二期：自定义头像图片与直接公开

### 里程碑 A：头像资产底座

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 对象存储 | 私有 Bucket、临时上传凭证、短期读取签名、源文件定时清理 | 无永久公网 URL；跨账号读取失败 |
| 图片处理 | JPG/PNG/WebP、魔数与解码校验、1:1 裁切、512×512 WebP、EXIF/GPS 清理 | 损坏/伪装/超大像素文件被拒绝；旧头像不被失败上传覆盖 |
| 生命周期 | AvatarAsset、档案绑定、历史引用、全局删除回退预设头像 | 删除后签名失效，24 小时内物理删除 |
| 告知同意 | 首次上传单独确认、同意版本记录、拒绝不影响核心功能 | 文案、隐私政策与删除路径可验收 |

### 里程碑 B：公开安全快照

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 脱敏策略 | 固定公开称呼替换昵称；识别电话、学校/班级、精确地址、账号标识、医疗诊断 | 标准风险语料不得进入公开快照 |
| 快照模型 | PREPARING/READY/BLOCKED/FAILED；私密原文与公开版分离 | 公共接口不能反向读取私密正文和定制快照 |
| 生成衔接 | 故事完成后异步准备；失败可重试，不阻断私密阅读/TTS | 正常情况下用户看到结果页时公开版已 READY |

### 里程碑 C：同步发布与撤回

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 发布确认 | 公开版预览、公开字段说明、单独确认、公开称呼选择 | 未确认无法发布；不展示审核状态 |
| 发布接口 | PRIVATE → PUBLIC、幂等、publishedAt、广场按发布时间排序 | 成功后 P95 ≤ 2 秒可查询；重复请求不重复写入 |
| 公共展示 | 复用故事广场/详情；公开 DTO 白名单；AI 生成标识 | 不展示自定义头像、今晚小事和 ChildProfile |
| 转为私密 | PUBLIC → PRIVATE、缓存清理、公共链接失效、互动保留 | P95 ≤ 2 秒下架，缓存最迟 60 秒失效 |

### 里程碑 D：公开后最小处置

| 工作包 | 内容 | 放行条件 |
| --- | --- | --- |
| 举报 | 公共详情入口、原因、限频、同用户去重、运营通知 | 可追踪且不泄露举报人 |
| 紧急下架 | 复用运营后台的一键下架、原因和操作日志、作者申诉提示 | 下架后不可自行再发布；公共访问立即失效 |
| 放量与回滚 | 内部 → 5% → 25% → 100%；独立功能开关 | 每档隐私、失败、撤回和举报指标通过后再放量 |

## 明确删除的原计划

- 不做“真人照片”主体限制，统一为自定义头像图片。
- 不做 PUBLIC_PENDING、人工前置审核、审核中/通过/驳回、审核回调和审核通知。
- 不做审核通过奖励或任何公开积分奖励。
- 不做头像公开展示、头像驱动插画/图生图、匿名发布和新广场路由。

## 技术评审必须给出的结论

1. 对象存储供应商、存储地域、签名与删除能力。
2. 公开快照脱敏实现、测试语料与失败降级。
3. 发布/撤回缓存失效策略及 P95 目标可行性。
4. 举报通知渠道、值班责任人和严重问题处置时限。
5. 各工作包负责人、依赖关系、估算人日和灰度日期。

## 固定回归清单

- 新私密故事在列表、详情、互动、解锁、异步生成各入口均被访问策略保护。
- 任意自定义头像都不会进入公共响应、广场、分享或评论。
- 公开故事使用公开安全快照；孩子昵称和生活隐私不随正文传播。
- 发布直接 PUBLIC；界面和数据中不存在 PUBLIC_PENDING。
- 转私密/平台下架后，公共列表、详情、分享、互动与缓存全部失效。
- 日志、埋点、错误上报不含昵称、今晚小事、图片 key/URL 或正文。
