深度定制化体验 PRD

把“一次性填表生成故事”升级为“产品记得孩子、今晚也听得懂”的睡前陪伴闭环。

状态：可进入技术评审 ｜ 创建：2026-09-03 ｜ 依据：运营汇总 OPS-2026-08-25-C、当前源码走查 ｜ Owner：产品

1. 概述与产品裁决

运营提出的 10 项诉求本质上不是 10 个独立功能，而是同一个信任问题：家长投入定制信息后，系统既没有记住，也没有显眼地用出来。第一性原理是先让每一份输入都可复用、可回显、可验证地影响故事；再扩充内容与长期陪伴资产。

本期裁决：先做“孩子档案 + 今晚素材 + 定制快照 + 专属回显”这一最小闭环（P0）。场景/主题/口味语气是创作页低风险增强（P1）；宠物成长、打卡、主角生成封面不进入本轮开发。
不把儿童照片送入 AI，也不承诺“照片生成封面”。照片仅在用户主动上传后用于档案和专属卡展示；默认采用预设头像。这样既兑现“看得见的专属感”，也避免未成年人肖像、存储、审核和图生图一致性风险。
运营项产品决策版本
OP-001完成页专属故事卡 + 详情页信息条；分享图后置P0
OP-002 / OP-003孩子档案、头像持久化、每篇故事不可变定制快照P0
OP-004一句话今晚素材 + 三种意图，写入 prompt 与回显P0
OP-005～008场景库、主题分类、口味/语气、音色扩展P1
OP-009～010伙伴宠物化、故事墙/打卡P2

2. 范围与优先级

P0：定制化最小可信闭环

  • 登录家长可新建、编辑、切换、归档孩子档案；每账号最多 5 份有效档案。
  • 创作页顶部有“今晚讲给谁”；选择档案后自动带入昵称、年龄段、性格、伙伴、头像，但本次临时编辑不反写档案。
  • 第三步新增可选“今晚的小秘密”：今天发生的事、今晚想解决的事、最近喜欢的事，以及一句话输入。
  • 创建故事时保存结构化定制快照；生成 prompt 使用孩子、伙伴、世界、主题和今晚素材。
  • 生成完成与故事详情回显“给 XXX 的第 N 个故事”和本次定制要素；历史故事无快照时平稳降级。
  • 补齐链路埋点与儿童隐私提示。

本期不做

  • 不做儿童照片生成插画、声音克隆、宠物等级、连续打卡、成长报告和付费权益。
  • 不改注册登录、不做游客创建；仅登录用户可建档和生成。
  • 不把今晚素材做成独立成长日记；本期仅随故事快照保存，后续须另获家长授权。
  • 不迁移旧故事、不伪造历史定制数据。

3. 用户、场景与指标

用户时刻任务成功感受
首次家长第一次做睡前故事2 分钟内建档并生成“它知道我家孩子是谁。”
回访家长睡前 5 分钟选中孩子，补一句今天发生的事“不用再填一遍。”
多孩家长为不同孩子讲故事切换正确孩子，故事归属清楚“不会混在一起。”

上线后 4 周目标：二次创作档案带入占比 ≥40%；含今晚素材的故事占比 ≥20%；专属卡曝光率 ≥90%；内测 N≥30 的“像为我家孩子写的”认同率 ≥60%。先采集基线再解读，不虚构用户量。

4. 用户流程与信息架构

首次：创作 → 登录 → “给谁讲”空态 → 新建档案 → 自动带入步骤 1 → 梦境世界 → 主题/今晚小秘密 → 生成 → 专属故事卡 → 阅读或朗读 回访：创作 → 选孩子档案 → 自动带入 → 仅补今晚小秘密（可跳过） → 生成 → 专属故事卡 多孩：创作 → 切换档案 → 确认是否覆盖当前主角设定 → 继续创作
位置内容规则
步骤 1 顶部头像、昵称、“今晚讲给”、切换未建档显示“先认识一下宝宝”；切换不直接丢弃输入。
步骤 1 主角编辑昵称、年龄段、性格、伙伴、头像由档案预填；只有主动点“同步到档案”才更新档案。
步骤 3成长主题、今晚小秘密今晚素材可跳过；选意图后给示例；输入上限 120 字。
生成完成专属故事卡主按钮“开始听故事”，次按钮“查看全文”。

5. 功能规格

5.1 孩子档案

字段规则说明
昵称1-12 字，必填；过滤联系方式/不当内容故事主角称呼
头像默认预设；上传 JPG/PNG/WebP，≤5MB，裁切 1:1提示“仅用于专属展示，不会生成真人图片”；失败可用默认头像。
年龄段0-2、2-4、4-6、6-8，必填影响既有 prompt 分龄约束
性格1-3 项，可编辑复用既有选项，避免自由标签污染 prompt
伙伴预设或 1-12 字自定义名P0 仍是文本/emoji，不升级宠物资产

入口：创作页空态、个人中心“我的孩子”。删除采用归档：不再可选但既有故事可读；归档后可恢复。达到 5 份上限时，须先归档一份。

5.2 今晚的小秘密

字段 tonightMaterial：三枚可选意图卡（今天发生的事、今晚想解决的事、最近喜欢的事），可不选直接输入。内容 1-120 字；提交前敏感检测。命中高风险时不进入模型，提示家长换一种说法并提供关怀提示。

5.3 定制快照、生成与回显

点击生成时，档案带入值与临时编辑值合并，保存为故事不可变 customizationSnapshot。生成任务只读取快照，而不是日后可能修改的档案；prompt 把今晚素材转为背景、待解决事项或兴趣元素，不得复述敏感原文、诊断心理问题或给医疗建议。

页面必须回显规则
完成页头像、给 XXX 的第 N 个故事、伙伴、世界、主题、素材摘要摘要最多 24 字；无素材不留空位；头像失败回退预设。
故事详情“本故事为 XXX 定制”、伙伴、世界、主题、日期折叠展示，不干扰阅读。
我的故事按孩子筛选P0 只做筛选；故事墙、打卡归 P2。

5.4 P1/P2 冻结说明

P1：场景扩至 12-15 张且使用本地受控素材；主题保留九宫格并可按四类浏览；最多 2 个口味与 3 个语气；TTS 至少 6 个已验证 Azure 音色。P2：伙伴升级宠物、故事墙与连续天数，必须在 P0 真实留存数据达标后重新立项。

6. 数据、接口与技术约束

ChildProfile：id, userId, nickname, avatarUrl, avatarType, ageGroup, traitsJson, partnerJson, status(ACTIVE/ARCHIVED), createdAt, updatedAt；索引 (userId, status) Story：新增 childProfileId（可空；不级联删除）；extData.customizationSnapshot = {schemaVersion, child, dreamWorld, growthTheme, tonightMaterial, flavorTags, storyTone}

优先新增 ChildProfile 与 Story.childProfileId；动态生成字段继续放既有 Story.extData。不要把多个孩子档案塞进 User.extData：查询、归档、权限与多孩扩展会不可维护。

接口用途硬约束
GET/POST /api/child-profiles列表、新建仅当前登录用户；校验 5 份上限、字段和敏感内容。
PATCH /api/child-profiles/:id编辑/归档/恢复所有权校验；归档不改历史快照。
POST /api/uploads/child-avatar头像上传鉴权、MIME/尺寸校验、私有存储/签名 URL；禁止可枚举公开目录。
POST /api/stories创建故事接收 childProfileId 与快照；服务端校验档案归属，不能信前端快照。
POST /api/stories/generate-async异步生成读取落库快照，补充 tonightMaterial 到 buildStoryConfig。
源码核对：异步生成已支持 flavorTags 与 storyTone，但 UI 无入口；当前头像是 blob URL；extData 已用于生成状态/TTS 脚本。因此必须安全合并 extData，并给快照加 schemaVersion，禁止覆盖写。

7. 状态、边界与安全

场景规则
无档案显示建档引导；不得以“小宝贝”等默认信息静默生成。
切换孩子当前主角已临时编辑时弹确认；覆盖主角字段，保留世界/主题/今晚素材。
上传失败预设头像 + 重试；不阻塞生成。
敏感素材阻止高风险文本进入模型；日志和埋点不保存原文。
归档档案关联故事仍可读；新生成不可选；可恢复。
并发生成同一用户同时仅 1 个任务，补齐幂等，避免重复扣分。
历史故事无快照则隐藏专属卡，不显示“未知孩子”。
隐私档案不出现在公共探索页；分享图默认不带上传头像；删号须清理头像对象与档案。

8. 埋点、验收与发布

事件触发属性（不得传姓名/素材原文/头像 URL）
child_profile_created建档成功ageGroup、hasAvatar、partnerType
child_profile_selected创作页选档profileCount、isReturning
tonight_material_added进入生成intent、textLength
story_customization_saved故事创建hasProfile、hasTonightMaterial、themeType、worldId
personal_story_card_viewed完成页卡曝光storyIndex、elementCount
  • 新用户可在 2 分钟内创建档案并生成；回访用户无需重填昵称、年龄、性格、伙伴。
  • 跨账号读取、编辑、用他人档案生成均返回 403；每故事仅有一份不可变快照。
  • 专属卡至少回显 5 个有效元素；缺失字段不显示 undefined 或空占位。
  • 今晚素材进入 prompt；超长、敏感、上传失败、历史故事、归档档案均可用降级。
  • 全量回归既有创作、异步轮询、TTS、插画、积分、故事列表；生成成功率不低于上线前 7 天基线。

灰度：先对内部/白名单开放 customizationV1Enabled，连续 3 天观察创建成功率、生成失败率、敏感拦截误伤和上传失败率。特性开关关闭后旧链路可用，新数据仍可读；迁移只新增，不阻塞历史。
