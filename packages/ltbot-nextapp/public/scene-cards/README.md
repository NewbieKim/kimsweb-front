# 场景卡片封面资产

- 用途：故事深度定制化第 2 步的 24 张 3:4 场景卡片。
- 生成方式：2026-09-05 使用 Codex 内置 `image_gen` 生成 4 张 2×3 分类母图，再无损定位裁切为 24 张 384×512 JPEG。
- 体积：单张约 30–68KB，满足 PRD 的移动端单图不超过 120KB 要求。
- 约束：无文字、无水印、无知名 IP、无恐怖/危险动作；卡片底部保留暗部供页面文字叠加。
- 使用规则：生产页面只引用本目录资产，不使用原型中的第三方图片热链。替换图片时保持文件名不变；若构图语义发生变化，同时升级 `SCENE_CATALOG_VERSION`。

## 最终提示词组

四组均使用 `illustration-story`，共同要求：高品质儿童睡前绘本、柔和 3D 手绘质感、2 列×3 行等分无间距母图、主体位于中上部、底部留暗部、无文字/字母/Logo/水印、无危险或惊吓内容。

1. 奇幻想象：云朵面包房、月亮邮局、星光森林、玩具王国、糖果浮岛、恐龙快递站；紫蓝夜空配暖金和粉色。
2. 自然探索：海底泡泡城、雨林树屋、极地星光站、昆虫旅馆、四季花谷、火山温泉谷；深海蓝、草木绿、冰雪青。
3. 科学发现：太空观测站、天气工厂、机器人实验室、身体小宇宙、交通发明城、恐龙考古营；靛蓝、实验室青和机械橙。
4. 温暖日常：外婆的魔法菜园、晚安图书馆、小小厨房、幼儿园夜游、社区便利店、家庭露营地；奶油米、烛光橙、木质棕和柔和夜蓝。
